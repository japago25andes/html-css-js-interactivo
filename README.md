# 🏠 Web en 3 capas: HTML · CSS · JavaScript

Página interactiva para entender **la diferencia entre HTML, CSS y JavaScript** y **cómo se complementan** en el desarrollo web.

👉 **Ver la página:** https://japago25andes.github.io/html-css-js-interactivo/

Está hecha solo con HTML, CSS y JavaScript, sin frameworks, para que el propio código sirva como ejemplo.

## ¿Qué incluye?

| Sección | Qué se aprende |
|---|---|
| **La casa** | Analogía: HTML = estructura, CSS = pintura, JS = electricidad. Con interruptores se enciende cada capa por separado o todas juntas. |
| **Cada uno por separado** | Qué es cada tecnología, un ejemplo de código y su resultado real. |
| **Laboratorio** | Una tarjeta de perfil real. Se activan y desactivan `index.html`, `styles.css` y `script.js` y se ve el resultado, el código y la consola del navegador. |
| **¿Cómo se complementan?** | Diagrama de Venn interactivo con las 7 combinaciones posibles y una tabla comparativa. |
| **El navegador paso a paso** | Cómo el navegador lee el HTML, construye el DOM, aplica el CSS, pinta la pantalla y ejecuta el JS. |
| **Quiz** | Siete preguntas de repaso. |

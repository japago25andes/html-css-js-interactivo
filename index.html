Fundamentos del desarrollo web

Toda página web se construye en 3 capas

Piensa en una página como una casa: HTML levanta la estructura, CSS la pinta y decora, y JavaScript le conecta la electricidad. Enciende cada capa y observa qué pasa.

Paso 1 · Conócelos

Cada uno por separado

Los tres viven en archivos distintos y cada uno responde a una pregunta diferente.

¿QUÉ hay en la página?

HTML · La estructura

HyperText Markup Language — lenguaje de marcado

  • Usa etiquetas como <h1>, <p>, <img> o <button>.
  • Organiza el contenido y le da significado: esto es un título, esto un párrafo, esto un botón.
  • No es un lenguaje de programación: no hace cálculos ni toma decisiones.
  • Es la base de todo: sin HTML no hay nada que mostrar.

🏠 En la casa: las paredes, puertas y ventanas.

index.html
Resultado

El navegador usa sus estilos por defecto: letra Times, fondo blanco y un botón gris que no hace nada.

¿CÓMO se ve?

CSS · La apariencia

Cascading Style Sheets — hojas de estilo en cascada

  • Selecciona elementos del HTML y les aplica estilos.
  • Controla colores, tipografías, tamaños, espacios y posiciones.
  • Adapta el diseño al celular o al computador (responsive).
  • Crea transiciones y animaciones.

🏠 En la casa: la pintura, los colores y la decoración.

styles.css
Resultado

Es el mismo HTML de la pestaña anterior. Solo agregamos CSS… y el botón sigue sin hacer nada.

¿Qué HACE?

JavaScript · El comportamiento

Lenguaje de programación de la web

  • Reacciona a eventos: clics, teclas, scroll, formularios…
  • Modifica el HTML y el CSS mientras la página está abierta (el DOM).
  • Toma decisiones, hace cálculos y guarda datos.
  • Se comunica con servidores para traer o enviar información.

🏠 En la casa: la electricidad, los interruptores y los bombillos.

script.js
Resultado · ¡haz clic en el botón!

Mismo HTML, sin CSS: se ve simple, pero ahora el botón cuenta tus clics.
